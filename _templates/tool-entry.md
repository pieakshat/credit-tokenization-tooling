### Tool name

- **Link:** primary source (official repository, documentation or EIP page)
- **Summary:** one factual sentence on what the tool does
- **Type:** contracts | SDK | service | spec | test suite | framework
- **Layer:** token | vault | compliance | accounting | NAV | redemption | cross-chain | custody | payments | admin | testing | data | defi
- **Chains:** EVM | Solana | …
- **License:** SPDX identifier, or the name of a custom license with a link to its text
- **Status:** specs only; the status shown on the EIP page (Draft, Review, Final)
- **Audit:** link to the published report(s); omit the field when none is published
- **Last checked:** YYYY-MM-DD
- **Use when:** the situation in which the tool is a fit
- **Notes:** license constraints, missing features, trust assumptions, maintenance state
